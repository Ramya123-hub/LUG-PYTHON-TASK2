# LUG-PYTHON-TASK2
* Celsius → Fahrenheit (Temperature)
* Kilometers → Miles (Distance)
* Kilograms → Pounds (Weight)
* Megabytes → Gigabytes (Data Storage)

### 🧠 How it works

1. Run the program
2. Choose a number from the menu (1 to 4)
3. Enter the value you want to convert
4. The program shows the converted result

### 🛠 What you need

* Python installed on your computer

### ▶ How to run

bash
python unit_coverter.py


### 🌟 Example
Enter choice: 2
Enter kilometers: 5
Miles: 3.106855
